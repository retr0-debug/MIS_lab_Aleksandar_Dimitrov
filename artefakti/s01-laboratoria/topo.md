
# Описание на мрежовата топология – S01 Лаборатория

## 1. Обща информация

Лабораторията е изградена във VirtualBox и включва две виртуални машини с операционна система Kali Linux – GW (Gateway) и SRV (Server).

GW разполага с три мрежови интерфейса. SRV е сървърна виртуална машина с един мрежов интерфейс, свързан към LAN1.

## 2. Виртуални машини

### GW (Gateway)

- Операционна система: Kali Linux
- Hostname: gateway
- Роля: Gateway / Router
- Брой мрежови адаптери: 3

Мрежови интерфейси:
- eth0 – WAN интерфейс, свързан към VirtualBox NAT.
- eth1 – LAN1 интерфейс, свързан към вътрешната мрежа LAN1.
- eth2 – LAN2 интерфейс, свързан към вътрешната мрежа LAN2.

### SRV (Server)

- Операционна система: Kali Linux
- Hostname: srv
- Роля: Server
- Брой мрежови адаптери: 1

Мрежов интерфейс:
- eth0 – свързан към вътрешната мрежа LAN1.

## 3. Мрежови сегменти

### WAN

- Тип: VirtualBox NAT
- Предназначение: Достъп на GW до интернет.
- Интерфейс на GW: eth0
- IP адрес: Получава се автоматично чрез DHCP.

### LAN1

- Тип: Internal Network
- Име във VirtualBox: LAN1
- Мрежа: 192.168.10.0/24
- Предназначение: Комуникация между GW и SRV.

IP адреси:
- GW (eth1): 192.168.10.1/24
- SRV (eth0): 192.168.10.10/24

### LAN2

- Тип: Internal Network
- Име във VirtualBox: LAN2
- Мрежа: 192.168.20.0/24
- Предназначение: Втори вътрешен мрежов сегмент, свързан към GW.

IP адрес:
- GW (eth2): 192.168.20.1/24

## 4. Топология

Интернет
    |
VirtualBox NAT (WAN)
    |
GW (Gateway)
    |-- eth0: WAN (DHCP)
    |-- eth1: LAN1 - 192.168.10.1/24
    |      |
    |      SRV - 192.168.10.10/24
    |
    |-- eth2: LAN2 - 192.168.20.1/24

## 5. Маршрутизация

GW е конфигуриран с активиран IPv4 forwarding:

net.ipv4.ip_forward = 1

Това позволява на системата да препраща IPv4 пакети между мрежовите интерфейси.

SRV използва GW като gateway за LAN1:

- Default gateway: 192.168.10.1

## 6. Чеклист

- GW и SRV имат различни hostname-и и IP адреси.
- SRV има ping до GW през LAN1.
- GW има достъп до интернет.
- IPv4 forwarding е включен на GW.
